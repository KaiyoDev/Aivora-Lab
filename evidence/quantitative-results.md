# Quantitative Results

## Hướng dẫn

File này lưu trữ các kết quả định lượng từ nghiên cứu, được trích xuất và chuẩn hóa.

**Quy tắc:**
- Giữ nguyên số liệu từ nguồn gốc.
- Ghi rõ đơn vị đo lường.
- Không làm tròn hoặc điều chỉnh số liệu.
- Luôn ghi source.

---

## Template Entry

### Result ID

### Bài toán
> Problem được đo lường.

### Dataset
> Dataset sử dụng.

### Model
> Mô hình thử nghiệm.

### Metric
> Chỉ số đánh giá (accuracy, F1, BLEU, ...).

### Kết quả
> Giá trị số (giữ nguyên).

### Baseline
> Kết quả baseline để so sánh.

### Cải thiện
> Mức cải thiện so với baseline.

### Statistical significance
> p-value, confidence interval (nếu có).

### Source
> Paper, URL, DOI.
